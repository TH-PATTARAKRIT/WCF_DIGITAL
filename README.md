# WCF DIGITAL

Public repository for controlled report-verification standards, reusable scripts, templates, and masked examples for the WCF DIGITAL project.

## Repository role

- **GitHub:** governance, reusable code, prompts, templates, configuration examples, and version history
- **Google Drive:** controlled source evidence and official deliverables
- **Jira:** tasks, defects, retest, and approval status
- **Google Sheets:** executive status register

## Data-publication rule

This is a public repository. Do not commit production PDFs, raw evidence, personal data, credentials, tokens, connection strings, or any dataset that can identify a person, employer, office transaction, or live system record.

## Governance

- No Evidence = No Progress
- WCFLEGACY = Source of Truth / Expected Result
- WCF = Production System / Actual Result
- WCFUAT = Development, Remediation and Retest Environment
- Boss is the sole final approver
- Do not close Jira or declare Production Ready without Boss approval
